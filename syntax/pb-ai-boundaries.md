# PB AI 协作边界

## 适合直接做的事

1. 解释 `.sr*` 源码
2. 基于 `manifest.json` 做导航与整理
3. 读取 `verify / report / diff` 做证据化分析
4. 生成候选修改、说明文档和审查结论

## 不能直接跳过的环节

1. 导出前置层
2. `verify`
3. `report`
4. 人工审查
5. 自动写回门禁

## 当前正式写回边界

当前正式支持矩阵不因为 toolkit 存在而改变。PB9 PBL 写回仍只应按 `Windows x86 + PBSpy + PBSDK` 理解。
