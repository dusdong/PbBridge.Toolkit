# PbBridge.Toolkit 7.5.0 发布说明

7.5.0 将当前业务运行时统一为 PowerShell 7.4+，并在既有 V3 共享库门禁中加入可重算的 freshness v1。它不新增顶层 CLI schema，不引入缓存或 TTL，也不改变 PBL 写回授权边界。

## 主要变化

1. 当前 Toolkit 模块、受管 wrapper、模板迁移与发布入口只支持 `pwsh` 7.4 或更高版本，不再回退到 `powershell.exe`。
2. `scripts/pbbridge-runtime-check.ps1` 是唯一可由旧宿主运行的零写入诊断入口；不满足要求时返回 `PWSH_7_REQUIRED`、实测宿主和安装/重跑指引。
3. `pbbridge-v3-shared-library-writeback-check` 保持 schemaVersion 3，在结果内增加 `pbbridge-shared-library-gate-freshness` schemaVersion 1。
4. freshness 绑定 workspace、被选中的共享库配置、Git/submodule 语义状态、允许参数以及实际消费的 manifest/verify 内容身份；report 只绑定存在性。
5. delivery、preflight 或 writeback 消费既有 gate 前重算输入；旧 7.4.x gate 或输入漂移返回 `SHARED_LIBRARY_GATE_INPUT_STALE` 并要求按当前 workspace 重建。

## 不变边界

- V3 外层 envelope、compact summary、迁移 schemaVersion 8、Plan/Decide/Apply、reason code 与 `ShouldProcess` 语义不变。
- 不引入 gate cache、TTL、后台刷新或 fleet 服务。
- 历史 JSON、session、schema evidence 与旧编码材料保持只读兼容，不重写原证据。
- 不自动执行 PBL Apply、PB9 IDE Full Build、业务验收、Git 提交或推送。

## 升级建议

先运行 `scripts/pbbridge-runtime-check.ps1`。确认宿主满足 PowerShell 7.4+ 后，用 `pwsh` 执行 Toolkit 升级和模板迁移。升级完成后，旧 7.4.x 共享库 gate 不再授权写回；应分别为每个 workspace 重新运行 `pbbridge shared-library writeback-check`。
