# PbBridge.Toolkit 7.4.2 发布说明

7.4.2 完成 7.4.1 未闭合的 Toolkit governance 热修：真实外部项目只安装 `.pbbridge/PbBridge.Toolkit` 时，upgrade-check 与 Git governance 现在使用同一份只读身份事实；历史 schemaVersion 4 证据不再触发空引用，也不会被误当成可信提交依据。

## 本次修复

- 新增共享 Toolkit identity 解析器，从父仓 gitlink、submodule HEAD、VERSION、内部状态和本地 remote-tracking refs 解析唯一 Toolkit 角色；同时支持外部项目 `.pbbridge/PbBridge.Toolkit` 与源码仓 `Toolkit/PbBridge.Toolkit`。
- Toolkit 候选冲突时返回 `TOOLKIT_IDENTITY_AMBIGUOUS` 并保持 review；不会按目录优先级猜测，也不会执行 `git fetch`。
- upgrade-check 为可提交条目绑定非空 Toolkit commit；普通文件复核 current/post-state SHA256，Toolkit gitlink 使用 submodule identity evidence，不伪造文件哈希。
- schemaVersion 4 reader 对旧字段缺失、null、错误类型和损坏 JSON 返回结构化 reasonCodes。历史条目保持 display-only/review，不会驱动 `UPGRADE_OWNED_CHANGE`。
- 默认 upgrade-check 结果改为 `.pbbridge/workspaces/<id>/results/toolkit-upgrade-check.json`；workspace 证据优先，全局文件只作 workspace 精确匹配的旧版回退。
- 发布回归夹具只构造一个 `.pbbridge/PbBridge.Toolkit` tracked submodule，并顺序验证 canyin、kuaican 的证据隔离、指针升级和受管文件归属。

## 兼容性边界

- 当前产品版本：`7.4.2`。
- V8 delivery schemaVersion：`8`；PBL drift schemaVersion：`4`；upgrade-check schemaVersion：`4`。
- 7.4.0 旧 upgrade-check 可以只读展示，但缺少当前绑定字段时不得驱动 commit。
- 本次不提供 schemaVersion 5、通用历史证据迁移器、网络 fetch、自动 Git add/commit、PBL Apply 或既有 PBV076/PBL drift 门禁豁免。

## 升级后检查

```powershell
pbbridge toolkit upgrade-check --repo-root . --workspace canyin --wrapper-smoke-scope all
pbbridge toolkit upgrade-check --repo-root . --workspace kuaican --wrapper-smoke-scope all
pbbridge git governance --repo-root . --workspace canyin
pbbridge git governance --repo-root . --workspace kuaican
```

若仓库保留旧的全局 `toolkit-upgrade-check.json`，无需删除或改写；重新运行当前 workspace 的 upgrade-check 即可生成权威隔离证据。
