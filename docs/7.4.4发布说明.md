# PbBridge.Toolkit 7.4.4 发布说明

7.4.4 是工作区级共享库门禁隔离补丁。它修复多工作区项目中共享库 gate 证据可能被另一个工作区的 `release-check` 或 `project-health` 读取的问题，不新增 CLI，也不改变现有 PBL 写回授权边界。

## 主要变化

1. 共享库 gate JSON 明确写出规范化 `workspaceName`，多工作区配置使用按工作区确定性排序的 `workspaceResults` 路由结果文件。
2. 项目模型只选择当前工作区唯一匹配的共享库 gate，并将选择结果纳入缓存身份；交替运行 `canyin`、`kuaican` 不会交换证据。
3. 当前工作区证据缺失、旧全局路径在多工作区中有歧义、重复配置冲突或结果身份不匹配时 fail-closed，分别返回稳定 reason code 和可执行的重跑建议。
4. 单工作区项目继续兼容既有 `resultJsonPath`；显式 `--workspace`、`--result` 与父输出参数优先于配置默认值。
5. 共享库初始化模板能识别受管工作区集合，并为多工作区项目生成可人工审查的 `workspaceResults` 草案。

## 不变边界

- 不新增 CLI 命令，不提升既有 JSON schemaVersion。
- 不自动执行 PBL Apply，不修改 `.sr*`、PBL 或 PBD。
- 不替代 PowerBuilder IDE Full Build 与业务验收。
- 不执行 Git 暂存、提交、推送或共享库指针更新。

## 升级与验收

升级后应分别为每个工作区运行共享库 gate，再运行对应工作区的 `release-check` 或 `project-health`。多工作区项目若仍只有不带身份的全局结果路径，将得到 `SHARED_LIBRARY_GATE_WORKSPACE_AMBIGUOUS`，应使用初始化器生成 `workspaceResults` 并为当前工作区重新生成 gate。

发布包验收从包内正式 CLI 与模板直接执行双工作区隔离场景，并核对源码快照、Toolkit 快照、provenance 与 checksum。CanYin 回归仅运行只读门禁，既有 PowerBuilder 源码与二进制哈希变化必须为 0。
