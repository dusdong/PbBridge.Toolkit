# 7.5.1 发布说明

7.5.1 是保持 V8 `schemaVersion=8` 的写回安全补丁。它不扩大自动创建 PBL、application 或 PB9 编译替代能力。

## 关键修复

- Apply 对目标 PBL 与全部 `CompileLibraryPaths` 建立稳定锁集合、锁内哈希重验和 write-ahead snapshot。
- importer 返回值、PBL 物理变化和对象反导验证作为三层独立事实记录。
- 任一只读编译依赖变化立即标记 `out-of-scope-write`，停止后续 batch 并要求显式恢复。
- importer 失败、异常或取消后若目标库变化，仍执行受限反导；实际写回数只统计 `verified-written`。
- `pbbridge rollback <snapshot.json>` 在覆盖前原子验证全部事故后哈希，恢复后以 `beforeSha256` 作二进制精确裁决。
- 新增对象写入零对象 PBL 时返回 `empty-target-manual-required`，由 PB9 IDE 人工处理。
- DryRun assurance 固定为 `importer-availability-verified`，不代表 PBSDK 编译、PB9 Regenerate、Full Build、运行或业务验收。

## 升级要求

7.5.0 preflight/session 只能作为历史证据，不能继续驱动 7.5.1 Apply。升级 Toolkit 后必须按 workspace 重新运行 V8 preflight。

## 能力边界

PB9 Full Build、运行和业务验收仍只接受 IDE 人工 evidence；新 PBL/application、多对象空库 bootstrap 和 Painter 二进制元数据继续由 IDE/ORCA 人工兜底。
