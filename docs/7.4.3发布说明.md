# PbBridge.Toolkit 7.4.3 发布说明

7.4.3 将 7.4.2 现场验证过的多决策确定性迁移修复并入正式 Toolkit 模块。Plan、Decide、Apply、reason code、ShouldProcess 与 schemaVersion 8 契约均保持不变；本版不新增 CLI 或治理功能。

## 主要修复

- 正式 `PbBridge.TemplateMigration.psm1` 统一从字典、`OrderedDictionary`、`PSCustomObject` 和 JSON 回读对象提取 canonical path。
- policy、decision、reusable request、plan request 与 awaiting decisions 全部使用 ordinal 排序，并复用同一个规范化数组完成哈希、持久化和消费。
- path 缺失、空白或忽略大小写重复时 fail-closed，且项目配置、源码与 PBL 写入数均为 0。
- 0、1、10 决策固定乱序向量在 Windows PowerShell 5.1、PowerShell 7 与 C# governance consumer 间产生相同 canonical bytes、`policyHash` 和 `decisionSetHash`。
- 10 决策流程可直接从包内正式模块完成 `Plan → Decide → Apply`，不再依赖临时 patched module 或 repair metadata。

## 发布一致性

发布门禁同时核对 canonical 模板源、Toolkit 快照和发布候选内正式模块的逐字节哈希，并直接从候选模块执行多决策向量。`invoke-pbbridge-7-4-2-deterministic-migration.ps1` 仅保留为不可变 7.4.2 的历史恢复工具，已弃用于 7.4.3 当前入口、模板和发布主路径。

## 兼容性与边界

- 当前产品版本：`7.4.3`。
- 模板迁移 schemaVersion：`8`，不变。
- Delivery schemaVersion：`8`，不变。
- project/workspace config schemaVersion：`7`，不变。
- 支持从 7.4.2 正式状态直接 Plan/Decide/Apply 升级。
- 不实施尚无可重复失败 fixture 的 `pbbridge-workspace-scoped-shared-library-gate`。
- 不替代真实项目的 PB9 IDE Full Build 或业务验收。
