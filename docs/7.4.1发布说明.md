# PbBridge.Toolkit 7.4.1 发布说明

7.4.1 是 7.4.0 的兼容性与治理判定热修，不扩大 PowerBuilder 自动化边界，也不改变现有 Delivery、PBL drift、upgrade-check、project/workspace 的 schemaVersion。

## 本次修复

- `delivery summary`、`delivery explain --why-blocked` 与 `delivery cleanup --what-if` 读取 7.3.2 旧会话时，返回 `compatibilityStatus=legacy-unsupported`、`errorCode=LEGACY_SESSION_UNSUPPORTED`、观测版本、最低支持版本、原因和下一步动作，不再抛出通用空引用。
- 旧会话在 `continue`、attestation、IDE 日志导入及底层 evidence/session 写入口统一 fail-closed；拒绝发生在创建临时证据或改写 session 之前。7.3.2 会话不自动迁移，必须重新运行当前 V8 preflight。
- Git governance 将父仓 HEAD gitlink、index gitlink、submodule HEAD、内部工作树状态和远端可达性作为正交事实。仅 Toolkit 指针升级、内部干净且提交可由本地远端跟踪引用证明时，才给出 `commit/TOOLKIT_POINTER_UPGRADE`。
- governance、hygiene 与 precommit 复用 schemaVersion 4 `upgrade-check` 的 `upgradeOwnedChanges`，并校验 workspace、产品版本、Toolkit 版本/提交、生成时间、路径和当前内容哈希。可信证据给出 `commit/UPGRADE_OWNED_CHANGE`；跨 workspace、版本不匹配或内容已变更时保持 `review` 并说明原因。

## 兼容性边界

- 当前产品版本：`7.4.1`。
- V8 delivery schemaVersion：`8`；PBL drift schemaVersion：`4`；upgrade-check schemaVersion：`4`。
- 最低可查询/续接的 session 产品版本：`7.4.0`。更旧 session 只返回结构化不支持结果，不合成对象执行或证据事实。
- 本次不提供通用旧会话迁移器、自动 Git add/commit、真实 cleanup 删除、PBL Apply、OCR 或通用证据图引擎。

## 升级后检查

```powershell
pbbridge toolkit upgrade-check --repo-root . --workspace canyin --wrapper-smoke-scope all
pbbridge git governance --repo-root . --workspace canyin
pbbridge delivery summary --repo-root . --workspace canyin --session <current-session-id>
```

若 session 来自 7.3.2，请保留其历史文件作为只读审计证据，并以当前 Toolkit 重新生成 preflight/session。
