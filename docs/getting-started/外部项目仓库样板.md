# 外部项目仓库样板

```text
AGENTS.md
pbbridge-project.json
.pbbridge/
  PbBridge.Toolkit/
  workspaces/
    canyin/
      workspace.json
      results/
      cache/
      policies/
      locks/
      recovery/
scripts/
  PbBridge.Wrapper.psm1
  pbbridge-delivery-close-loop.ps1
  pbbridge-delivery-continue.ps1
src/
  <library>.pbl.src/
```

## 最小约定

1. `AGENTS.md` 引用 Toolkit `CODEX-START.md`，声明 PBW/PBT、共享库、Git 与 IDE 验收边界。
2. `.sr*` 是受管业务源码；对象键为 `<workspace-relative-pbl-path>:<object-type>:<object-name>`。
3. V8 预检使用 `pbbridge-delivery-close-loop.ps1`，写回只使用 `pbbridge-delivery-continue.ps1`；wrapper 不实现 workspace、readiness、summary 或 recovery。
4. 每个 workspace 的 manifest、result、cache、policy、lock 与 recovery 物理隔离。
5. `.pbbridge/local/`、临时 re-export、IDE 日志和 token 默认不提交。
6. 非当前 delivery/session JSON 必须拒绝，升级后重新运行当前 V8 preflight。

```powershell
./scripts/pbbridge-delivery-close-loop.ps1 -RepoRoot . -Workspace canyin -Object 'app.pbl:window:w_example=src/app.pbl.src/w_example.srw' -ResultJsonPath '.pbbridge/workspaces/canyin/results/delivery-v8/preflight.json'
./scripts/pbbridge-delivery-continue.ps1 -RepoRoot . -From '.pbbridge/workspaces/canyin/results/delivery-v8/preflight.json' -Apply
```
