# V8 交付证据闭环使用手册

PbBridge.Toolkit `7.5.3` 使用 V8 硬切：`delivery close-loop` 只预检，`delivery continue` 才写回。

```powershell
pbbridge delivery close-loop --repo-root . --workspace canyin --object "app.pbl:window:w_main=src/w_main.srw" --result .pbbridge/workspaces/canyin/results/delivery-v8/preflight.json
pbbridge delivery continue --from .pbbridge/workspaces/canyin/results/delivery-v8/preflight.json --apply
```

只有目标路径、对象身份、存在性、基线校验和和冲突预检全部完成且冲突数为零时，`writebackReadiness` 才能为 ready。Continue 会恢复原请求并重新检查事实新鲜度，默认生成独立的 `*-apply.json`。

每次 preflight 自动创建 session；后续 packaging、deployment、IDE 日志和 attestation 都追加为不可变证据。handoff 始终读取 session 最新状态。

DryRun 不证明 PB 编译、部署、运行或业务正确性。
