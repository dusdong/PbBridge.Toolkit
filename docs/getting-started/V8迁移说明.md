# V8 迁移说明

当前版本不提供非当前 Delivery/session 到 V8 的 JSON 转换。旧输入返回 `unsupported` 或 `invalid`，升级后必须重新执行当前 V8 preflight。

旧 close-loop 写回选项统一返回 argument-error；当前文档不再列出或分发这些过期命令。

替换为：

```powershell
pbbridge delivery close-loop ... --result preflight.json
pbbridge delivery continue --from preflight.json --apply --result apply.json
```

project/workspace 配置 schema 保持原版本；运行依赖清单独立使用 `pbbridge-runtime-dependency-manifest` schemaVersion 1。
