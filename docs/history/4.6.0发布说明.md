# 4.6.0 发布说明

`4.6.0` 是 writeback session cache 与诊断聚合版本，目标是降低连续写回同一 PBL 时的重复解析和重复上下文准备成本。

## 主要变化

1. `pbbridge writeback close-loop` 默认启用本机 session cache，并输出 `sessionId`、`sessionCacheStatus`、`cacheHits[]`、`cacheMisses[]`、`elapsedMs` 等字段。
2. `pbbridge-writeback-close-loop.ps1` 透传 `-Session`、`-NoSessionCache`、`-SessionRetentionDays`。
3. Apply 路径增加同 PBL 本机 lock，避免并发写回同一目标 PBL。
4. `pbbridge diagnostics summary --session <sessionId>` 可聚合同一 session 的多次 close-loop 结果。
5. 新增 `pbbridge writeback session list` 与 `pbbridge writeback session prune --older-than <days>` 管理本机 session cache。

## 边界

session cache 只优化 `.pbbridge/local/` 下的本机只读上下文和工作区准备；它不是交付事实源。Apply 前仍会重新计算当前源码 hash、目标 PBL hash、compile library hash，并沿用 v4 stale guard。跨 PBL close-loop、跨机器共享缓存、数据库级 DataWindow SQL 校验和自动 IDE Full Build 不在本版范围内。
