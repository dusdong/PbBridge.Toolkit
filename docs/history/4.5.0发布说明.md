# 4.5.0 发布说明

`4.5.0` 是 DataWindow 专项校验版本，同时收口 `4.4.0` close-loop 真实项目反馈。

## 主要变化

1. `pbbridge-writeback-close-loop.ps1` 默认结果文件名改为首对象短名加 16 位 hash，降低 Windows 长路径风险。
2. PowerShell wrapper 支持 `-Objects` alias，并明确多对象传参使用 `-Object @("...","...")` 或 `-Objects @("...","...")`。
3. `closeLoopVerdict=dryrun-only` 时，`blockingIssueCount` 不再把“等待确认 Apply”或 `not-written` 当作阻断。
4. 新增 `pbbridge datawindow validate <source.srd> [--strict]`，输出 `pbbridge-datawindow-validate`。
5. `datawindow inspect` 扩展 retrieve SQL/PBSELECT、arguments、SQL 参数、select alias、column/dbname 匹配和结构化 issues。
6. DataWindow 对象接入 `writeback close-loop`：明确 mismatch 在 Apply 前阻断，并进入 close-loop 交付摘要。

## 边界

DataWindow 校验只做源码结构级判断，不连接数据库，不验证真实表结构或 SQL 语义，不生成 `.srd` 骨架。跨 PBL close-loop、依赖图和跨命令 session reuse 仍留到后续版本。
