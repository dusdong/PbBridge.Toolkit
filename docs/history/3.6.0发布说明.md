# 3.6.0 发布说明

`3.6.0` 是 V3 契约模块化与证据治理收口版本。它不改变 v3 共同字段，不引入 v4 schema，不扩大 PB9/ORCA 支持矩阵，不新增未准入写回路径。

## 1. 契约模块化

V3 契约实现继续拆分为 workflow registry、schema summary builder、example factory 和 workflow-specific validator。`pbbridge schema show <workflow>`、`pbbridge contract validate <json>`、`schemaName=pbbridge-v3-*`、`schemaVersion=3` 和基础退出码语义保持不变。

## 2. 只读诊断与证据治理

只读诊断继续拆分 fact reader 与 bundle manifest writer。`project adoption check`、`diagnostics summary`、`diagnostics bundle create` 和 `diagnostics bundle verify` 继续只消费 CLI/Core JSON facts，不解析 stdout 文本，不重新解析 PBW/PBT/PBL。

本版引入轻量证据术语：`workflowFact`、`handoffBundle`、`releaseProvenance`、`releaseAssetHandoff`、`localOnlyEvidence`、`legacyImportDiagnostics`。这些术语用于交接说明和测试，不改变现有 v3 JSON 字段。

## 3. CLI command descriptor

CLI 增加轻量 command descriptor，用于收敛命令名、workflow、schemaName、help 摘要、分组命令 normalization 和 contract route coverage。旧 wrapper 名称不等于旧 JSON 契约；结果 JSON 仍必须使用 `pbbridge-v3-*`。

## 4. 发布和 Toolkit 边界

Release engineering 继续把 release notes summary、tag guard、release provenance 和 release asset handoff 下沉到共享 helper。Toolkit sync 继续推进高变化 docs/skills/templates 文件化，脚本只负责复制、占位符替换、版本对齐和一致性报告。

PowerShell wrapper、Toolkit skill 和 SharpIDE 仍只消费 CLI/Core JSON，不承载 PowerBuilder 业务规则。
