# 3.7.1 发布说明

`3.7.1` 是 V3 Toolkit 契约一致性与日志降噪热修版。它不改变 v3 共同字段，不引入 v4 schema，不扩大 PB9/ORCA 支持矩阵，不新增未准入写回路径。

## 主要变化

1. `pbbridge pbl change-intake` 的结果补齐 `workspaceModel`，success、blocked、failed 路径都能通过 v3 workflow-aware contract validation。
2. `pbl-change-intake` 的 `artifacts[]` 合并项目模型 evidence，实际 `.pbbridge/pbl-change-intake.json` 可直接用于 `pbbridge contract validate`。
3. `readonly-sync --summary-only --compact`、`project model show --compact`、`project adoption check --compact` 只缩短 stdout，完整 v3 JSON 仍写入 `--result` 或默认 state 文件。
4. 外部项目模板 `.gitignore` 与 `template-manifest.json.localIgnoredRoots` 默认忽略 `.pbbridge/cache/`、根级 workflow state JSON、diagnostics bundle 本机目录和临时状态文件。

## 边界

compact stdout 只用于大型项目日常交互降噪，不作为跨 workflow 事实源。CI、Toolkit skill、SharpIDE 只读展示和 `diagnostics summary --run-missing` 仍必须读取完整 CLI/Core JSON 文件。

`.pbbridge/adoption-baseline.json` 与 `.pbbridge/policies/*.json` 仍可作为经评审事实源提交；本机 cache、state JSON 和 diagnostics bundle 目录默认不提交，除非项目有明确证据归档策略。
