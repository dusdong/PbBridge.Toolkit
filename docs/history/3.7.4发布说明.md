# 3.7.4 发布说明

`3.7.4` 是 `3.7.3` 之后的 V3 Toolkit 模板迁移分类热修版。它不改变 v3 共同字段，不引入 v4 schema，不扩大 PB9/ORCA 支持矩阵，不新增未准入写回路径。

## 变更

1. `pbbridge-template-migrate.ps1` 更稳定地识别受管 wrapper 的项目化默认参数差异，并归类为 `project-configuration`。
2. 参数归一化覆盖 `readonly-sync`、`pbl change-intake`、`pbl-binary-baseline` 和同类 `pbbridge-*` wrapper。
3. 支持单行数组、多行数组、单双引号、`Parameter`/`ValidateSet` 属性和从 mandatory 参数改为项目默认值的场景。
4. 当项目参数差异和模板主体差异同时存在时，迁移报告继续保留模板漂移结论，并通过 `projectConfigurationDiffs[]` 提示应保留的项目参数。

## 不变项

本热修不改变 `3.7.3` 的 compact stdout、退出码矩阵、`source-hygiene` 聚合、`PBV076` advisory 或 diagnostics `recommendedNextCommand` 行为，也不自动覆盖外部项目脚本。
