# PbBridge Toolkit 2.10.0 发布说明

`2.10.0` 是发布修复、结构收敛与性能基线治理版本。它修复 `2.9.0` 外部项目拉取后暴露的版本元数据不一致问题，并继续收敛高频 SR 单对象导入链路的 Core/CLI 结构。

## 关键修复

1. Toolkit manifest、runtime contract、CLI artifact source 与模板版本统一到 `2.10.0`，避免模板迁移因 `productVersion` 旧值被 blocked。
2. `pbbridge import-object` 对对象无变化返回 `decision=no-change` 的成功结果，不再以 `INVALID_OPERATION` 打断日常判断。
3. `import-object` 命中 shared-library 且请求 Apply + WriteBack 时，会阻断快路径写回并提示改走 `scripts/pbbridge-import-plan.ps1` 专家链路；DryRun 仍可用于快速判断。

## 结构收敛

1. Core 继续拆分导入职责，新增 plan builder、post-apply review service、rollback service 和 file summary service。
2. CLI 继续按命令族拆分 handler，`CommandRouter` 更集中于顶层分派。
3. PowerShell 模板仍保持复制即用，不引入外部 `.psm1` 依赖。

## 性能治理

1. `import-object` 继续输出 `performance.stageTimings`、`slowPathReasons` 与 `skippedHeavySteps`。
2. 默认快路径仍不得隐式执行 full diff、full verify 或 release-check。
3. 本版新增测试入口说明，便于按 Core、CLI contract 与 PowerShell 模板分层回归。
