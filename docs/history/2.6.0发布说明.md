# PbBridge Toolkit 2.6.0 发布说明

`2.6.0` 是多 PBW 外部项目协作版本，重点解决同一仓库中 `CanYin.pbw`、`KuaiCan.pbw` 这类多个 PBW 共存时的证据隔离问题，并把 PowerBuilder 编译选项等 `.sr*` 不可见的 `.pbl` 二进制变化提升为可提交、可审查的策略证据。

## 核心变化

1. CLI `export` 支持具体 `.pbw` 文件输入；使用 `workspace-targets` 时只扫描该 PBW 引用的 `.pbt`，不会枚举同目录其他 PBW。
2. manifest 增加可选字段 `workspaceInputPath`、`workspaceName`，旧消费者可继续忽略。
3. 外部模板脚本支持 `-WorkspaceName`，命名工作区写入 `.pbbridge/workspaces/<name>/artifacts/pbbridge`、`baseline/pbbridge`、`logs/` 和 `state/`。
4. `default` 工作区继续兼容顶层 `.pbbridge/release-check.json`、`.pbbridge/project-health.json` 等旧路径；非 default 工作区不写顶层状态。
5. 新增 `.pbbridge/policies/pbl-binary-baselines.json` 与 `pbbridge-pbl-binary-baseline.ps1`，用于登记 PowerBuilder 编译选项、project options、metadata-only 等已评审二进制基线。
6. readonly sync、pbl-change-intake 和 release-check 会识别工作区 `.pbl` 是否只是 Git LFS pointer 文本，并以 `PBL_WORKTREE_LFS_POINTER` 阻断。

## 推荐命令

双 PBW 项目分别刷新本机基线：

```powershell
.\scripts\pbbridge-readonly-sync.ps1 -WorkspaceName canyin -WorkspacePath CanYin.pbw
.\scripts\pbbridge-readonly-sync.ps1 -WorkspaceName kuaican -WorkspacePath KuaiCan.pbw
```

PowerBuilder IDE 已直接修改快餐工程 `.pbl` 后接入：

```powershell
.\scripts\pbbridge-pbl-change-intake.ps1 -WorkspaceName kuaican -WorkspacePath .\KuaiCan.pbw
```

登记编译选项二进制基线：

```powershell
.\scripts\pbbridge-pbl-binary-baseline.ps1 -WorkspaceName kuaican -WorkspacePath KuaiCan.pbw -PblPath kc_ht.pbl,kc_lptprn.pbl,kc_qt.pbl -ReasonCode powerbuilder-compile-options -Reason "PowerBuilder IDE compile options baseline"
```

登记后复核：

```powershell
.\scripts\pbbridge-pbl-drift-remediation.ps1 -WorkspaceName kuaican
.\scripts\pbbridge-release-check.ps1 -WorkspaceName kuaican -AllowBlockedResult
```

## 升级注意

1. 旧项目不传 `-WorkspaceName` 时仍使用 `default`，行为保持兼容。
2. 多 PBW 项目必须把 PBW 文件和工作区名一起固定，例如 `CanYin.pbw -> canyin`、`KuaiCan.pbw -> kuaican`。
3. `.pbbridge/workspaces/` 仍是本机可再生目录，不提交。
4. `.pbbridge/policies/pbl-binary-baselines.json` 是可提交策略文件，但不得包含机器私有路径、token 或未经评审的 `.pbl`。
5. `PBL_LFS_FILTER_MISMATCH` 仍只是 Git 策略诊断；真正的工作区 PBL pointer 文本由 `PBL_WORKTREE_LFS_POINTER` 阻断，必须先恢复真实 PBL。
