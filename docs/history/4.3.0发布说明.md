# 4.3.0 发布说明

`4.3.0` 是 v4 PBL 对象写回结论一等化版本，不扩大 PB9/PBSpy/PBSDK/ORCA 支持矩阵。

## 关键变化

1. DryRun full JSON 可直接作为 Apply `--preflight-result`；`writeback object` 外层 DryRun 会跟随 `importResultJsonPath`，compact summary 会跟随 `resultJsonPath`。二次重发后，Apply 只读取 DryRun JSON 中的必要 facts，历史 full JSON 的无关字段形态不兼容时不得泄漏 Object/Array 底层异常。
2. v4 写回结果新增 `targetObjectWritebackVerdict`、`writeBackAppliedState`、`targetPblChanged`、四段 verdict 和 `driftClassification[]`。
3. 新增 `pbbridge writeback object` 与 `scripts/pbbridge-writeback-object.ps1`。
4. projection-only 默认将本地与投影内容相同的文件判定为 no-op，且默认不删除业务源码；stale 投影只作为候选输出，必须显式传 `--allow-delete-projection` 才会删除；`--refresh-object-key` 的最终写回范围严格限制为目标对象。
5. Apply 失败但 `targetPblChanged=true` 时，先按对象级 verdict、before/after hash 和 recover evidence 判断 PBL 风险，再决定是否需要 IDE Full Build 或人工恢复。
