# PbBridge Toolkit 2.6.1 发布说明

`2.6.1` 是 LC_PS 真实项目反馈补丁版，聚焦生产写回诊断与选择性同步；不扩大 PB9 写回支持矩阵，不把 ORCA candidate 升级为正式支持。

## 关键变化

1. `pbbridge import` 新增 `--source-encoding auto|utf-8|gbk|utf-8-bom|utf-16le`，默认 `auto`，用于控制 `.sr*` 导入前的解码预检。
2. import 结果和 PBSpy 诊断会记录 `decodePreflight`、`normalizedSourcePath`、`sourceLineEnding`、`highRiskObjectType` 和编译消息源码上下文，便于排查 `CompileEntryImport -11`。
3. 新增 `pbbridge git change-audit <commit>`，只读列出提交中的 `.sr*` 对象新增、删除、修改和重命名，并标记删除对象、事务变更、入口隐藏和 PB9 ORCA 高风险对象类型。
4. `pbbridge-import-sr.ps1` 新增 `-SourceEncoding` 和 `-SourceOnlyAccepted`；`pbbridge-source-accepted.ps1` 可生成 `.pbbridge/source-accepted-checklist.json`，表达“源码已选定，PBL 等 PowerBuilder IDE Regenerate / Full Build”。

## 边界

1. 本版不自动转码 `.sr*`。
2. 本版不改变 `.pbl/.pbd` 二进制提交策略。
3. 本版不自动执行 PowerBuilder IDE Regenerate 或 Full Build。
4. ORCA 仍是显式 candidate，正式 PB9 PBL 写回路径仍是 Windows x86 + PBSpy + PBSDK。
