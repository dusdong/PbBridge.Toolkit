# 4.0.1 发布说明

`4.0.1` 是 `4.0.0` 的 import-source 编译上下文热修版本，不移动已发布的 `v4.0.0` tag，也不扩大 PB9/PBSpy/PBSDK/ORCA 支持矩阵。

## 修复内容

1. `pbbridge import source --workspace <projectRoot> --workspace-name default --writeback` 会按项目根解析 `.pbbridge/workspaces/default/artifacts/pbbridge/manifest.json`。
2. `SourceFactSet.compileLibraries[]` 保留 PBW/PBT LibList 中的只读 PBL/PBD，例如 `pb-libs/Lib_Query.pbl`。
3. scratch preflight 的 `finalLibraryList` 继续以 scratch target PBL 为首，并追加 staged/copy 后的 readonly PBL 依赖。
4. 缺 manifest 且请求 `--writeback` 时返回 `failureCategory=manifest-required-for-pbt-context`。
5. `pbbridge-v4-import-source` 顶层输出 `diagnosticsBundleJsonPath` 与 `rollbackVerdict`。

## 外部项目升级

`scripts/pbbridge-import-source.ps1` 新增 `-WorkspaceName` 参数，默认 `default`，并透传 CLI `--workspace-name default`。外部真实项目验证默认只做 DryRun，不执行 PBL Apply 写回。
