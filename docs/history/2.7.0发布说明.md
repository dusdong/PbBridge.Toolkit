# PbBridge Toolkit 2.7.0 发布说明

`2.7.0` 聚焦对象级验证降噪、post-apply drift 精确定位与高风险对象执行包，不扩大 PB9 写回支持矩阵。

## 关键变化

1. `pbbridge-import-sr.ps1` 新增 `-VerifyScope object|target-pbl|all`，对象级导入默认 `object`。
2. import 结果新增 verify scope 摘要字段，区分 scoped issue 与 excluded historical issue。
3. post-apply review 新增 `postApplyReviewDrifts[]`，输出对象/member 级 drift 明细。
4. 新增 `pbbridge-import-package.ps1`，可为 `menu/window/datawindow` 等高风险对象创建并执行导入包。

## 示例

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\pbbridge-import-sr.ps1 -ObjectKey lib.pbl:window:w_main -VerifyScope object

powershell -ExecutionPolicy Bypass -File .\scripts\pbbridge-import-package.ps1 -PlanJsonPath .\.pbbridge\workspaces\default\artifacts\pbbridge\plan-import.json -Mode DryRun
```

`VerifyScope object` 不等于全项目发布门禁通过；发布前仍需 `verifyScope=all`、release-check、PowerBuilder IDE Regenerate / Full Build / 运行验收。
