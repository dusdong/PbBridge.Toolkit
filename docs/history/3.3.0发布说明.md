# 3.3.0 发布说明

`3.3.0` 是 V3 外部项目规模化接入与证据交接增强版本。它不改变 v3 基础字段，不引入 v4 schema，不扩大 PB9/ORCA 支持矩阵，不新增未准入写回路径。

## 关键变化

1. `pbbridge project adoption check --profile <profile>` 支持 `standalone`、`shared-library-self`、`shared-library-consumer` 和 `legacy-pb9`，输出 `adoptionProfile`、`profileChecks[]` 和 `profileEvidence[]`。
2. `pbbridge diagnostics bundle create` 输出 `schemaName=pbbridge-v3-diagnostics-bundle`，生成 bundle manifest、关键 JSON facts、Git/submodule 摘要、SHA256 和 local-only evidence。
3. release engineering summary 新增 `releaseProvenance`，记录 version、commit、tag、tagCommit、Toolkit、CLI、release manifest、SHA256SUMS、runtime contract、release artifacts、checks、status 和 nextActions。
4. release/tag guard 同时支持 annotated tag 和 lightweight tag，按 tag 指向的 commit 与 HEAD 对齐。
5. Toolkit skills、docs 和模板路由补充 adoption profile、diagnostics bundle 和 CI/wrapper 退出码消费口径。

## 推荐命令

```powershell
pbbridge project adoption check --project-root . --profile standalone
pbbridge project adoption check --project-root . --profile shared-library-consumer
pbbridge diagnostics summary --project-root .
pbbridge diagnostics bundle create --project-root .
pbbridge contract validate .\.pbbridge\diagnostics-bundle.json
```

`diagnostics bundle` 是证据索引，不替代原始 JSON、日志、release-check 或 PowerBuilder IDE Regenerate / Full Build / 运行验收。

## 边界

PowerShell wrapper 仍只负责 CLI 调用、路径适配、日志落盘和 JSON/退出码透传；SharpIDE 仍只消费 CLI/Core JSON facts，不解析 PBW/PBT/PBL，不实现 shared-library gate、release-check 或写回阻断规则。`exit 10` 仍表示业务阻断，不是脚本崩溃。
