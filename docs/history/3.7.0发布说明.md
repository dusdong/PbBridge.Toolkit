# 3.7.0 发布说明

`3.7.0` 是 V3 Toolkit 执行效率与诊断快路径增强版本。它不改变 v3 共同字段，不引入 v4 schema，不扩大 PB9/ORCA 支持矩阵，不新增未准入写回路径。

## 主要变化

1. Toolkit runtime cache：`.pbbridge/cache/toolkit-runtime.json` 记录 CLI/Toolkit/template 版本、manifest hash 和 runtime contract hash，供 wrapper 判断是否需要重复调用 CLI。
2. Workspace model cache：`.pbbridge/cache/workspace-model.<hash>.json` 缓存 `PbWorkspaceModel` 事实，输入变化时由 CLI/Core 自动失效重建。
3. Diagnostics summary 快路径：`pbbridge diagnostics summary --run-missing` 优先读取已有 JSON facts，缺失时只按需补齐只读 facts。
4. Toolkit preflight：`pbbridge toolkit preflight` 在单个 CLI 进程内聚合 runtime、项目模型和 diagnostics summary。
5. Toolkit sync 增量化：`scripts/sync-toolkit-assets.ps1` 基于 checksum 跳过未变化文件，`-RefreshRuntimeEvidence` 显式刷新 runtime evidence。
6. Release engineering preflight：`scripts/build-release-engineering.ps1 -PreflightOnly` / `-VerifyOnly` 只跑快速只读门禁，不重新 publish 或压缩 release artifacts。

## 边界

缓存只作为 CLI/Core JSON facts 的审计快照。PowerShell wrapper、Toolkit skill 和 SharpIDE 仍只透传或展示 JSON 与退出码，不解析 PBW/PBT/PBL，不实现 shared-library gate、release-check、project drift 或写回阻断规则。
