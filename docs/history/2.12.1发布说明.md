# PbBridge Toolkit 2.12.1 发布说明

`2.12.1` 是 `2.12.0` 后的真实项目反馈补丁版，不引入 CLI 契约 v3，不扩大 PB9 写回支持矩阵。

## 关键变化

1. `pbbridge datawindow inspect` 增加 `visualControls[]`，可列出 `.srd` 中 `column(band=header.1 ... name=xxx)` 这类视觉 column/control。
2. `datawindow inspect` 增加 `setFilterCandidates[]`，用于区分可参与 Column[] / SetFilter 的数据源列。
3. `datawindow inspect` 增加 `riskHints[]`，提示非 detail band、视觉控件未匹配数据源列等排障风险。
4. `import-object no-change + --apply --writeback` 的 shared-library gate 摘要会明确说明没有实际导入步骤，因此 gate 为 `not-applicable`。

## 边界

1. DataWindow inspect 仍是轻量文本解析，不依赖 PowerBuilder IDE，不参与 import gate 或 release gate 阻断。
2. `visualControls[]` 只表达 `.srd` 视觉控件事实，不等价于可直接用于 `SetFilter()` 的数据源列。
3. CLI 成功仍不代表 PowerBuilder IDE Regenerate、Full Build 或业务运行验收通过。
