# PbBridge Toolkit 2.7.1 发布说明

`2.7.1` 是 2.7.0 后续补丁，聚焦两个现场反馈点：包装脚本 PBL drift guard 的空集合绑定，以及 CLI apply 阻断信息的可操作性。

## 修复内容

1. `pbbridge-import-sr.ps1 -ObjectKey ... -Apply` 在无 `.pbl` 状态变更时，不再因为 `Add-GitStatusPblPaths -Paths` 空集合绑定而提前失败。
2. `import Apply` 遇到 plan 阻断项时，错误信息会说明 `ForceApply` 只处理 target drift/import conflict，不会绕过 verify 阻断。
3. 对 `PBV076` 阻断，错误信息会提示 `.srf` 结构污染原因，并建议使用 `pbbridge suggest-fixes <artifactsRoot> --code PBV076` 辅助定位。

## 边界

`PBV076` 仍是阻断项。正确修复方式是让 `.srf` 只声明和实现对象自身函数，而不是通过 `ForceApply` 写入结构污染。
