# PbBridge Toolkit 2.12.0 发布说明

`2.12.0` 是 `2.11.0` 后的写回体验闭环版本，不引入 CLI 契约 v3，不扩大 PB9 写回支持矩阵。

## 关键变化

1. `pbbridge import-object --apply --writeback` 命中配置内共享库时，会自动运行只读 `shared-library writeback-check`；gate clear 后继续写回，blocked、证据缺失或配置异常时阻断。
2. import-object JSON 追加 shared-library gate result path 与摘要，旧字段继续保留。
3. post-apply review 仅有 metadata-only drift 且正文/结构漂移为 0 时，摘要明确输出 `autoAccepted=true` 与原因。
4. 新增 `pbbridge import confirm-object <objectKey>`，只读执行对象 re-export、verify 和 diff，确认 `.pbl` 是否加载当前 `.sr*`。
5. 新增 `pbbridge datawindow inspect`，只读解析 `.srd` 或 DataWindow object key 的 columns、bands、coltype 和 Edit.Style。

## 边界

1. shared-library gate 不提交、不推送、不更新 submodule pointer。
2. DataWindow inspect 只做轻量排障，不参与 import gate 或 release gate 阻断。
3. CLI 成功仍不代表 PowerBuilder IDE Regenerate、Full Build 或业务运行验收通过。
