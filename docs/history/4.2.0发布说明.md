# 4.2.0 发布说明

`4.2.0` 是 v4 写回可信度与项目交接硬化版本，不扩大 PB9/PBSpy/PBSDK/ORCA 支持矩阵。

## 重点变化

1. CLI 与 wrapper 默认结果、staging、diagnostics、re-export review 统一进入 `.pbbridge/local/`。
2. 新增 `pbbridge source preflight`，在 DryRun 前做 PB 源码级编码、字符串闭合、DataWindow 片段和 PB9 中文风险预检。
3. v4 import/writeback 结果新增 `sourcePreflightSummary`、`sourceDiagnostics[]`、`compileContextSummary`、`reExportReviewSummary` 和 `ideValidationVerdict`。
4. 新增 `pbbridge toolkit upgrade-check` 和 `scripts/pbbridge-toolkit-upgrade-check.ps1`，输出 `ready|needs-template-merge|blocked|failed`。
5. 新增 `pbbridge git hygiene suggest`，区分建议提交、忽略和人工确认。

真实 `.pbl` Apply 仍需显式人工确认。Apply 成功只表示 PBL 已写入，PowerBuilder IDE Regenerate / Full Build / 运行验收仍是必需的外部验收步骤。
