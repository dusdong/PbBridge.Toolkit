# PbBridge Toolkit 2.9.0 发布说明

`2.9.0` 是高频 SR 单对象快速导入与性能专项治理版本，目标是让日常对象级修复从专家链路变成稳定、快速、可观测的主命令。

## 重点变化

1. 新增 `pbbridge import-object <objectKey>`，默认 `verifyScope=object`，复用已有 baseline/current artifacts，不隐式触发全量 diff 或全量 verify。
2. 新增 `templates/external-project/pbbridge-import-object.ps1`，外部项目可复制到 `scripts/` 作为日常单对象导入入口。
3. 新增 `templates/external-project/pbbridge-import-plan.ps1` 承载复用计划、SourceOnlyAccepted、共享库 gate、冲突检查、DryRun/Apply 等专家链路。
4. `pbbridge-import-sr.ps1 -ObjectKey` 在普通对象导入场景下转入 `import-object` 快路径，减少历史 verify 噪声和等待时间；`-PlanJsonPath` / `-UseExistingPlan` 分流到 `pbbridge-import-plan.ps1`。
4. 导入结果新增短摘要、实际 SR 路径、hash、diagnostics run 路径与 `performance` 节点。
5. diagnostics bundle 支持 `diagnostics-bundle/runs/<runId>/index.json`，同时保留 `diagnostics-bundle/index.json` latest 兼容入口，降低并发导入互相抢写风险。

## 推荐用法

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\pbbridge-import-object.ps1 -ObjectKey '<library:objectType:objectName>'
powershell -ExecutionPolicy Bypass -File .\scripts\pbbridge-import-object.ps1 -ObjectKey '<library:objectType:objectName>' -Apply -WriteBack
```

需要复用已人工审阅的计划时，继续使用 `pbbridge-import-sr.ps1 -PlanJsonPath <plan>`。
也可以直接调用专家入口：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\pbbridge-import-plan.ps1 -PlanJsonPath '<plan-import.json>'
```

## 兼容性

- `plan-object-import`、`import`、`import-package` 保持兼容。
- 本版不扩大 PB9/PBSpy/ORCA 写回支持矩阵。
- 性能验收以阶段计时、慢路径标记和消除隐式全量工作为准，不承诺固定秒级 SLA。
