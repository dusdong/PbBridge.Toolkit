# PbBridge Toolkit 2.11.0 发布说明

`2.11.0` 是 CLI/Core 外部项目维护入口下沉版本。它保持 `Windows x86 + PBSpy + PBSDK` 仍为正式 PB9 写回路径，ORCA 仍为 candidate，不扩大真实写回支持矩阵。

## 关键变化

1. `pbbridge workspace readonly-sync` 默认执行 export、verify、report、source-hygiene 和 baseline refresh。
2. `pbbridge workspace readonly-sync --summary-only` 保留旧 evidence 摘要行为。
3. `pbbridge pbl change-intake` 与 `pbbridge shared-library writeback-check` 已下沉到 CLI/Core；PowerShell 同名脚本只作为外部项目入口包装。
4. 配置在 `.pbbridge/shared-libraries.json` 中的共享库，专家链路 gate 通过后默认允许继续 Apply/WriteBack，不再要求额外共享库写回授权。
5. project health、release check、PBL drift remediation 和 precommit summary 继续优先使用 CLI/Core 结构化 JSON。

## 边界

1. readonly sync 只刷新只读投影、本机 evidence 和 baseline。
2. CLI 成功不代表 PowerBuilder IDE Regenerate、Full Build 或业务运行验收通过。
3. shared-library gate 失败、配置缺失、证据缺失或脚本异常仍必须在 Apply/WriteBack 前阻断。
4. 本版不自动提交、不自动推送、不更新 submodule pointer，不把 ORCA candidate 表述为 supported。
