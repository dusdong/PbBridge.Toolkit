# 4.1.0 发布说明

`4.1.0` 是 v4 写回体验增强版，不扩大 PB9/PBSpy/PBSDK/ORCA 支持矩阵，也不做 5.0 级破坏性删除。

## 主要变化

1. `import-source` 结果新增 `preflightSummary`、`rawPreflightResultJsonPath`、`targetPblRiskVerdict`、`scratchRecoveryVerdict`、`pbCompileFailureCategory`、`pbCompileFailureConfidence` 和 `ideFallbackRecommended`。
2. `pbbridge diagnostics summary --result <json>` 可聚焦当前 v4 import/writeback 结果，优先读取顶层 `diagnosticsBundleJsonPath`，避免误读项目级旧状态。
3. rollback 摘要按真实 target PBL 风险表达；scratch 恢复状态不会被写成真实 PBL 已恢复。
4. 新本机证据默认进入 `.pbbridge/local/`，包括 results、diagnostics-bundle、staging、scratch-preflight 和 re-export-review。
5. AGENTS 模板去除项目占位事实，新增 `templates/external-project/agents-snippets/` 可合并片段。
6. 模板迁移器可识别旧 `pbbridge-import-source.ps1` 近似模板，只缺 `WorkspaceName` 时自动补丁。

## 兼容边界

只读 workflow 继续使用 v3 common fields；import/writeback 稳定消费面继续使用 v4。v3 import/writeback JSON 只作为历史证据，不作为 4.1.0 默认稳定契约。
