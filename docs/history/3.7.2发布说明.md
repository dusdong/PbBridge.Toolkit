# 3.7.2 发布说明

`3.7.2` 是 `3.7.1` 之后的 V3 Toolkit 日志降噪与退出码热修版。它不改变 v3 共同字段，不引入 v4 schema，不扩大 PB9/ORCA 支持矩阵，不新增未准入写回路径。

## 主要变化

1. `pbbridge workspace readonly-sync --compact` 在完整同步路径输出 `pbbridge-v3-compact-summary`，stdout 不再包含完整 `workspaceModel`。
2. `pbbridge pbl change-intake --compact` 输出 compact summary，完整 `pbbridge-v3-pbl-change-intake` 仍写入结果文件。
3. `readonly-sync status=blocked` 固定返回 exit `10`，包括 compact stdout 路径；exit `1` 只表示真实执行失败。
4. 外部项目 `pbbridge-readonly-sync.ps1` 与 `pbbridge-pbl-change-intake.ps1` 新增 `-Compact`，只透传 `--compact` 并保持 CLI 退出码原样返回。

## 边界

compact stdout 只用于大型项目日常交互降噪，不作为跨 workflow 事实源。CI、Toolkit skill、SharpIDE 只读展示和 `diagnostics summary --run-missing` 仍必须读取完整 CLI/Core JSON 文件。

本热修不改变 `3.7.1` 的 `pbl-change-intake workspaceModel` 契约、不改变模板 ignore 口径，也不修复业务项目中的 PBV076 或本机 `sys.ini` 变更。
