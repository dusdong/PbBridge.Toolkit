# 3.10.0 发布说明

`3.10.0` 是 V3 写回正确性版本。核心变化是 import/writeback 默认使用 PBW/PBT `LibList` 构建编译上下文，同时保留 `ExcludeLibrary` 只控制源码事实源范围的语义。

## 主要变化

1. 历史 3.10.0 曾为 `pbbridge import`、`import-object`、`import-objects` 新增 `--compile-context pbt|managed-only`，默认 `pbt`；`managed-only` 当时仅作为旧行为兼容和排障开关，当前 5.0.1 已拒绝该旧输入。
2. `CompileLibraries` 和 PBSpy `finalLibraryList` 默认保留 PBT 完整依赖顺序：目标 PBL 优先，其余 PBL/PBD 按 LibList 首次出现顺序追加并稳定去重。
3. scratch PBL preflight 选择性构建 scratch baseline，不再递归复制完整 baseline；只复制本次 plan 的目标写回 PBL 和 plan 相关 target source 文件，只读 PBL/PBD 编译依赖保留原路径引用，同 PBL 批量对象只复制一次目标库；目标 PBL 不可解析时输出 `scratch-target-pbl-unresolved` 并阻断真实 Apply；`import-objects` 同 PBL gate 在 manifest-only 阶段使用 resolved target PBL，无法解析或多目标 PBL 时跳过 body diff、source hash、dryRun/preflight/apply，并按 resolved target PBL 输出 `pblBatches[]`。
4. `import-objects` 的 plan/diff/dryRun/apply/preflight/shared-library gate/scratch root 文件名改为稳定短 batch id，避免大量 objectKey 拉长路径；hash 后缀按对象集合稳定，文件名前缀使用当前命令首个对象短名；完整对象事实源继续读取 `objectKeys[]`、`objectResults[]` 与 `pblBatches[]`，新增对象的相对 `LibraryFilePath` 按 current manifest `WorkspaceRoot` 解析，`resolvedSourceHash` 优先复用 manifest checksum。early blocked 可以没有真实 DryRun JSON，但完整结果仍必须提供 `haltReason`、`nextCommand`、`checks[]` 和 `pblBatches[]`；early blocked 的 diff/plan 标记为 `manifest-only target gate evidence`，plan step reason 会保留原始 reason 后追加 marker，不代表已确认源码正文 drift。
5. manifest/project model 追加 `libraryRole=managed-source|readonly-compile-dependency|target-writeback|companion-pbd`；shared/submodule PBL 默认只作为只读编译依赖参与写回上下文。
6. `CompileEntryImport -11` 诊断追加 `missingCompileDependencies[]`、`compileContextMode`、`compileContextSource`、`haltReason` 和 `nextCommand`，用于定位 `Illegal data type` / `Unknown object` 等缺依赖场景；缺依赖 reason 至少区分 managed-only 过滤、文件缺失、路径解析不一致和 final list 意外遗漏；阻断后的 `nextCommand` 使用 PowerShell-safe quoting。
7. 模板迁移中已有 `AGENTS.md` 无条件归类为 `manual-snippet-merge`，禁止自动 `overwrite-with-backup` 覆盖项目私有规则。
8. `pbbridge-init-shared-libraries.ps1` 默认过滤 `.pbbridge/*`、Toolkit、IDE 和桥接工具目录，只保留具备 PowerBuilder 库特征或常见共享库名称的候选。
9. 历史快照：`scripts/sync-toolkit-assets.ps1` 默认 stdout 只输出 compact summary；完整 checksum 事实源写入 `Toolkit/PbBridge.Toolkit/checks/SHA256SUMS.txt`，旧完整 JSON stdout 不再作为当前推荐入口。

## 推荐用法

父项目仍可用 `ExcludeLibrary pb-libs/*, pb-langchao/*` 避免纳管共享库源码；写回窗口、菜单、用户对象时保留默认 `--compile-context pbt`，让编译上下文接近 IDE 的 PBW/PBT LibList。

```text
import-object/import-objects DryRun -> Apply -WriteBack -> 查看 resultJsonPath -> PowerBuilder IDE Regenerate / Full Build
```

## 历史兼容说明

本版不引入 v4 schema，不扩大 PB9/ORCA 正式支持矩阵，不自动修复业务源码或 PBL。历史 3.10.0 中 `--compile-context managed-only` 可复现旧上下文，但当前 5.0.1 已统一要求 `--compile-context pbt` 并对 `managed-only` 返回 argument-error。
