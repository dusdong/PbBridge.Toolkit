# PbBridge.Toolkit 6.0.0 发布说明

6.0.0 是 delivery 架构破坏性重构版本。

## 核心变化

1. `pbbridge-v6-delivery` 与 `pbbridge-v6-compact-summary` 成为唯一当前 delivery 契约。
2. 新增独立 `PbBridge.Delivery` domain/application/ports/presentation 分层；CLI 仅做解析、调度、展示和退出码映射。
3. full 与 compact 复用 canonical `DeliveryRun` 与 `summary`，移除重复聚合和 V4→V5/current mapper。
4. DryRun、Apply、ApplyIfEligible、post-apply review、跨 PBL saga、恢复状态和缓存统一进入 application workflow。
5. 自动写回与 V6 共用 `IAutoApplyPolicyEvaluator`，策略 deny 原因结构化，token 永不明文落盘。
6. V4/V5 delivery 输入统一返回 `unsupported-schema-version`，必须重新运行 V6 DryRun。
7. PowerShell wrapper 使用共享 `PbBridge.Wrapper.psm1`，V6 wrapper 支持 `ShouldProcess`、流式 stdout/stderr 与原生退出码透传。
8. 源码格式分析拆为独立服务，区分 Git 属性预期转换、格式噪声与业务变化。
9. Toolkit 文档、skills、CODEX-START、external project AGENTS、runtime、checksum 和 template manifest 全部切换到 6.0.0。

## 升级门禁

升级后必须重新生成 V6 DryRun；不得复用任何旧 delivery JSON。Apply 后必须完成反向确认与 PowerBuilder IDE Regenerate、Full Build、运行验收。
