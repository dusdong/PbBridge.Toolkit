# V6 交付闭环使用手册

PbBridge `6.0.0` 将 `pbbridge-v6-delivery` 设为唯一当前交付契约。主链为：源码修改 → V6 DryRun → 显式 Apply 或 ApplyIfEligible → post-apply review → IDE 验收。

## 1. DryRun

```powershell
pbbridge delivery close-loop --object "app.pbl:window:w_example=src/app.pbl.src/w_example.srw" --progress text --result .pbbridge/local/results/delivery-v6/dryrun.json
```

DryRun 成功时应满足：

- `phase=dry-run`
- `outcome=ready-to-apply`
- `apply.readiness=ready`
- `writeback.outcome=not-attempted`
- `objects[].existence=not-checked|unknown|exists|missing`，不得用写回结果猜测存在性
- `diff.planned` 描述待写入对象与源码变化，`diff.residual.evaluationStatus=not-evaluated`
- `nextCommand` 给出可复制的 Apply 命令

## 2. 显式 Apply

```powershell
pbbridge delivery close-loop --object "app.pbl:window:w_example=src/app.pbl.src/w_example.srw" --apply --preflight-result .pbbridge/local/results/delivery-v6/dryrun.json --progress text --result .pbbridge/local/results/delivery-v6/apply.json
```

CLI 会校验 V6 schema、workspace/request/facts hash 和新鲜度；不匹配时要求重新 DryRun。Apply 后必须读取 `writeback`、`review`、`conflicts`、`recovery` 和 canonical `summary`。

## 3. ApplyIfEligible

```powershell
pbbridge delivery close-loop --object "app.pbl:window:w_example=src/app.pbl.src/w_example.srw" --apply-if-eligible --policy .pbbridge/policies/auto-apply.json --token-env PBBRIDGE_AUTO_APPLY_TOKEN --progress jsonl --result .pbbridge/local/results/delivery-v6/auto.json
```

技术 DryRun 与共享策略 evaluator 必须同时允许才进入 Applying。策略结论只读 `policy.decision` 与 `policy.reasonCodes[]`；token 来源可以被审计，但 token 明文不得落盘。

## 4. full 与 compact

stdout compact 与 full result 共享同一个 `summary`、`outcome`、`nextCommand` 和 `blockedItems`。自动化不得从对象数组重新聚合计数，也不得再读取 V4/V5 结果补字段。

`summary` 使用带 `evaluationStatus` 的计数表达计划差异、DryRun/Apply 失败、PBL 写回、写入对象、反导匹配、格式/业务残余差异、冲突和复核，并显式给出 `partialWriteback`、`recoveryRequired` 与 `canProceedToIdeFullBuild`。

## 5. 进度与源码格式

交互终端默认显示阶段文本；非交互 stdout 保持单个 JSON。可显式选择 `--progress none|text|jsonl`。

源码格式读取 `objects[].sourceFormat`：

- `current` 与 `original`：encoding、BOM、line ending、EOF newline、trailing whitespace 快照
- `delta`：各格式维度是否变化以及内容/归一化内容是否变化
- `classification`：预期 Git 属性转换、纯格式噪声、业务内容变化或未知风险

## 6. IDE 交接

```powershell
pbbridge delivery ide-checklist --result .pbbridge/local/results/delivery-v6/apply.json
pbbridge delivery ingest-ide-log --result .pbbridge/local/results/delivery-v6/apply.json --log .pbbridge/local/ide/full-build.log
pbbridge delivery handoff-summary --result .pbbridge/local/results/delivery-v6/apply.json
```

只有 `summary.canProceedToIdeFullBuild=true` 才进入 IDE Full Build；最终仍需 PowerBuilder Regenerate、Full Build 和运行验收。
