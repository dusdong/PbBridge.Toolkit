# 3.7.3 发布说明

`3.7.3` 是 `3.7.2` 之后的 V3 Toolkit 只读诊断体验增强版。它不改变 v3 共同字段，不引入 v4 schema，不扩大 PB9/ORCA 支持矩阵，不新增未准入写回路径。

## 主要变化

1. `pbbridge diagnostics summary --compact`、`pbbridge release check --compact` 和 `pbbridge project health --compact` 输出 `pbbridge-v3-compact-summary`，完整 JSON 仍写入结果文件。
2. v3 workflow 退出码通过回归测试固化：`status=success` 返回 exit `0`，`status=blocked` 返回 exit `10`，`status=failed/argument-error` 返回 exit `1`；已有 `--allow-blocked-result` 例外保持显式。
3. 模板迁移能把 PBW、workspace、scan scope、include/exclude library、source layout 和 verify policy 等默认参数差异归类为 `project-configuration`，不再误判为可覆盖脚本漂移。
4. `source-hygiene` 增加按原因和处置动作聚合，summary/compact 输出优先展示可忽略、需修复、需策略登记和需复核分类。
5. `PBV076` 建议更明确地区分对象自身函数和污染函数，提示拆分、重新导出和检查对象归属。
6. `diagnostics summary` 增加 `recommendedNextCommand`，在 blocked 场景下给出最短下一步命令。

## 边界

compact stdout 仍只用于日常交互降噪，不作为跨 workflow 事实源。CI、Toolkit skill、SharpIDE 只读展示和 `diagnostics summary --run-missing` 必须读取完整 CLI/Core JSON 文件。

本增强不自动修复业务项目中的 PBV076，不修改 `.sr*` 或 `.pbl`，也不改变写回支持矩阵。
