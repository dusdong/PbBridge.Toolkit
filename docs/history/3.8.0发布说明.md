# 3.8.0 发布说明

`3.8.0` 是 V3 写回与诊断体验版本。核心变化是所有 V3 workflow 默认 stdout 输出 `pbbridge-v3-compact-summary`，完整事实写入 `resultJsonPath` 指向的 JSON 文件；当时的旧脚本可通过 `--full-json-stdout` 请求完整 stdout。该参数属于历史行为，当前 5.0 已删除并拒绝该旧输入，自动化必须读取 `resultJsonPath`。

## 主要变化

1. V3 workflow 默认 stdout 降噪，`--compact` 保留为兼容参数，自动化必须读取 `resultJsonPath`。
2. `import-object` 增加 scratch PBL preflight、baseline-intake 分流、target/ambient blocker 字段，并在写回失败诊断中补充 normalized source、source context、编译消息和推荐处理路径。
3. project model 支持 `.pbbridge/library-set.json`，并可从 `shared-libraries.json` 的显式库集合建模无 PBW/PBT 的共享库目录。
4. `import-package create/run` 也写入完整 V3 workflow 结果文件，stdout 只保留摘要。

## 兼容说明

本版不引入 v4 schema，不扩大 PB9/ORCA 正式支持矩阵，不自动修复业务源码或 PBL。compact stdout 只用于人机交互和低 token 摘要，不能作为事实源。
