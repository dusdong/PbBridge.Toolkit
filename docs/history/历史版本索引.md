# PbBridge.Toolkit 历史版本索引

本文档只保留对未来开发、迁移和排障有价值的历史信息。`PbBridge.Toolkit` 远端仓库仍按最新版二进制快照维护：不补回旧 `runtime/`、PDB、压缩包、旧 tag 或完整 Git 历史。

## 1. 使用范围

本文档用于回答以下问题：

1. 某项 Toolkit 能力从哪个版本开始出现。
2. 外部项目升级时需要关注哪些契约变化。
3. 哪些历史问题不能在后续版本中重复引入。
4. 哪些支持矩阵结论是正式支持，哪些只是 candidate 或历史证据。
5. 如何根据父仓发布 tag、manifest、checksum 与 provenance 审计或重建历史分发。

本文档不作为旧版本下载入口，不承诺旧版本可 checkout。

## 4. 契约演进摘要

### 4.1 JSON 与退出码

1. `3.0.0` 起，V3 workflow 统一使用 `schemaName=pbbridge-v3-*` 与 `schemaVersion=3`。
2. `4.0.0` 起，import/writeback workflow 统一使用 `schemaName=pbbridge-v4-*` 与 `schemaVersion=4`；只读 workflow 可继续使用 v3。
3. v4 import/writeback 不允许 `success` 作为状态；`applied` 必须同时满足 `writebackVerdict=applied` 且 `pblWritebackCount > 0`。
4. v4 `blocked` 返回 exit `10`，`failed` 返回 exit `1`，`argument-error` 返回 exit `2`，`recovery-required` 返回 exit `12`。
5. 自动化消费必须读取完整 JSON 文件，不以 compact stdout 或摘要文本作为事实源。

### 4.2 manifest 与工作区

1. `2.0.0` 起默认写入 manifest v5。
2. 旧 state 必须通过 `pbbridge manifest validate` 检查，并重新 export 或 readonly-sync。
3. `1.0.3` 起默认 PBL 同目录源码布局，路径显示不等于公共对象主键；对象定位仍优先读取 manifest。

### 4.3 Toolkit runtime

1. `1.0.2` 起 Toolkit 固定携带 `runtime/pbspy/win-x86/PBSpy.dll` 与 `PBSDK/`。
2. `2.5.0` 起 `toolkit-runtime-contract.json` 与 `manifest.json.runtimeContract` 是发布门禁的一部分。
3. 当前快照仓库禁止提交 PDB，`SHA256SUMS.txt` 不包含 PDB 条目。

### 4.4 发布与仓库策略

1. Toolkit 远端只保留最新版快照。
2. 旧分发事实通过父仓发布 tag、manifest、checksum 与 provenance 审计；需要回滚时从对应父仓源码重新构建当前快照。
3. Gitee GC 后仍超限时，允许删除并重建同名仓库，再推送当前单提交快照。
4. 父仓 release/tag guard 仍可维护父仓发布 tag；Toolkit 仓库不再保留 tag。

## 5. 未来开发使用规则

新增功能、修复或迁移文档时，按以下规则判断是否补充本索引：

1. 影响外部项目升级路径时，必须补充。
2. 改变 CLI JSON 字段、退出码、manifest、runtime path 或模板管理边界时，必须补充。
3. 改变 PB9/PBSpy/PBSDK/ORCA 支持矩阵时，必须补充。
4. 只是内部重构、测试整理、日志措辞变化，且不影响消费契约时，可以不补充。
5. 任何二进制文件、PDB、ZIP、完整日志目录、旧 tag 或旧提交历史都不得作为“历史信息”补回。

## 6. 与主仓文档的边界

本文档在主仓和 Toolkit 子仓中都会出现，但定位不同：

1. 主仓版本是事实源，用于维护者判断是否需要补充历史索引、维护发布 provenance 和调整同步策略。
2. Toolkit 子仓版本是分发副本，用于外部项目理解当前快照为什么不保留旧二进制、旧 tag 或旧提交历史。
3. 如果需要修改版本结论、支持矩阵、恢复策略或文档边界，先改主仓本文档，再运行 `scripts/sync-toolkit-assets.ps1` 同步到 Toolkit。
4. Toolkit 子仓中本文档不得作为旧版本下载入口，也不得作为恢复旧 runtime 的授权说明。
