# PbBridge Toolkit 2.7.2 发布说明

`2.7.2` 是 `2.7.1` 后续文档与 skill 补丁版，聚焦外部 PowerBuilder 项目在 `project-health blocked` 后的清理顺序。本版不改变 CLI 写回语义，不放宽 `PBV076`，也不让 `ForceApply` 绕过 verify 阻断。

## 主要变化

1. 新增 [project-health blocked清理指引](../reference/project-health-blocked清理指引.md)，把 `PBV076 managed-blocker`、缺 `source-hygiene`、缺 `release-check`、缺 `.pbbridge/shared-libraries.json`、未解释 `.pbl` drift、dirty 子模块和 IDE 验收缺口串成固定处理顺序。
2. 更新 `pbbridge-project-health` skill：V3 起 `project-health` 返回 exit 10 时通常表示健康状态 blocked，exit 1 只表示真实执行失败。
3. 更新 `pbbridge-release-preflight`、`pbbridge-project-maintenance-router` 和 `pbbridge-cli` skill，强调发布判断必须回到 release-check、Git/submodule、drift evidence 和 PowerBuilder IDE 验收。

## 未改变的边界

1. `PBV076` 仍是结构污染阻断项，必须修复 `.srf` 后重新 verify / plan / import。
2. `ForceApply` 只用于接受 target drift 或 import conflict，不绕过 verify blocker。
3. `source-hygiene.json` 不能单独解释 `.pbl` 漂移。
4. CLI Apply 成功不等于 PowerBuilder IDE Regenerate / Full Build / 运行验收通过。
