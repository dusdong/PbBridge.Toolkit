# PbBridge Toolkit 3.1.0 发布说明

`3.1.0` 是 V3 契约落地体验与发布可靠性增强版本。它不扩大 PB9/ORCA 支持矩阵，不新增未准入写回路径，也不把 SharpIDE 变成 PowerBuilder 业务规则引擎。

## 重点变化

1. `pbbridge contract validate <json>` 增强 workflow-aware 诊断，失败项包含 `path`、`expected`、`actual` 和 `nextAction`。
2. 新增 `pbbridge project model show`，输出 `schemaName=pbbridge-v3-project-model`，用于解释 workspace、targets、libraries、source layout、manifest facts、shared-library role/evidence 和 consumer 关系。
3. import/writeback 状态机继续固定 `plan -> dryrun -> apply -> writeback -> post-apply-review -> re-export -> verify`，并收敛稳定 `failureCategory`。
4. 发布工程新增 release/tag guard，默认禁止静默移动已存在或已推送 tag，并输出 `pbbridge-v3-release-engineering-summary` 摘要。
5. `pbbridge-contract-diagnostics`、`pbbridge-cli` 和维护路由 skill 已补充 3.1.0 诊断和命令路由。

## 消费建议

1. wrapper 和 CI 继续以 `schemaName=pbbridge-v3-*`、`schemaVersion=3` 为准，不消费旧 JSON 名称。
2. 只读展示层优先消费 `project-health`、`release-check`、`readonly-sync` 和 `project model show` JSON。
3. `AllowBlockedResult` 只保留 JSON，不改变 `status=blocked` 或 `exit 10` 的业务语义。
4. 发布前先看 release engineering summary 与 tag guard 状态，再进入人工打 tag / 推送流程。
