# PbBridge Toolkit 2.7.3 发布说明

`2.7.3` 是 `2.7.2` 后续模板一致性热修版，解决外部项目 release-check 报 `TEMPLATE_VERSION_MISMATCH` 的问题。

## 修复内容

1. `template-manifest.json` 的 `templateVersion` 与所有受管模板文件头 `PbBridge-TemplateVersion` 保持一致。
2. `scripts/sync-toolkit-assets.ps1` 不再把部分模板重新生成为旧 `2.6.1` 标记，而是按当前 `VERSION` 动态写入。
3. 增加模板迁移测试，覆盖所有受管模板的版本标记与 manifest 版本一致。

## 未改变的边界

1. 本版不改变 CLI 写回语义。
2. `PBV076` 仍是 verify blocker，不能由 `ForceApply` 绕过。
3. `2.7.2` 的 `project-health blocked` 清理指引继续保留。
